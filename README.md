# contaAlura

Exercício do curso de Java: a primeira aplicação de conta.

![Java](https://img.shields.io/badge/Java-ED8B00?style=flat-square&logo=openjdk&logoColor=white)
![License](https://img.shields.io/badge/License-MIT-F05138?style=flat-square)

## O problema

O primeiro contato com Java costuma vir por um exercício de console: ler
entrada, modelar um objeto, formatar saída. Não resolve nada prático — ensina
a sintaxe que o resto do curso vai exigir.

## O que exercita

- Leitura de dados do teclado com `Scanner`
- Modelagem de extrato com `List<Conta>`
- Formatação de CPF, CNPJ e telefone
- Exceções próprias para regra de negócio

## Rodar

```bash
javac -d bin src/App.java
java -cp bin App
```
