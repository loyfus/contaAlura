# contaAlura

Exercicio do curso de Java: a primeira aplicacao de conta.

## O que exercita

- Leitura de dados do teclado com `Scanner`
- Modelagem de `extrato` com `List<Conta>`
- Formatacao de CPF, CNPJ e telefone
- Excecoes proprias para regra de negocio

## Como rodar

```bash
javac -d bin src/App.java
java -cp bin App
```

## Nota

Codigo de exercicio de curso, mantido como registro da trilha de Java.
A configuracao de pasta vem da IDE (`.vscode/`).
